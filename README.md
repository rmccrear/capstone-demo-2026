# Potluck Joy

Connecting people to their potlucks.

This app will help potluck goers to organize their meals.

## Wireframe

![wireframe](./wireframe.png)

## Target User

Potluck users who want to join a potluck, but need to share their meals.

## Features to include

1. list potluck meals
2. view details of meal
3. a form to add meals.

## Features to exclude

1. potluck events
